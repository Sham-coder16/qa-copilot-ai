\# QA Copilot AI - Interview Discussion



\## Project Explanation



QA Copilot AI is an AI-powered testing assistant that analyzes automation failures and provides intelligent recommendations.



It uses:

\- TypeScript backend

\- Express API

\- MCP server

\- Groq LLM

\- Playwright reports





\## My Contribution



I designed and developed:



\- MCP server architecture

\- AI analysis workflows

\- REST APIs

\- Prompt engineering

\- Test report processing

\- CI/CD pipeline integration
